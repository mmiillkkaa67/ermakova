# Журнал событий устройства
База данных SQLite для хранения событий интеллектуальных устройств (термостаты, датчики): включение, выключение, показания, ошибки. Помогает находить неисправные устройства.

## Структура таблиц
| Таблица | Столбцы |
| --- | --- |
| devices | device_id (PK), name, location |
| events | event_id (PK), device_id (FK → devices), event_time, event_type, value |

event_type принимает значения: 'включение', 'выключение', 'показание', 'ошибка'.
value заполняется только для события 'показание', для остальных NULL.

## Развёртывание базы данных с нуля
1. Создать таблицы: sqlite3 shop_devices.db < schema.sql
2. Загрузить данные: sqlite3 shop_devices.db < data.sql
3. Выполнить запросы: sqlite3 -header -column shop_devices.db < queries.sql

Файл базы *.db в репозиторий не попадает (см. .gitignore).

## Вывод по диагностике
Чаще всего об ошибках сообщает «Термостат-01» в офисе 101: за утро он дважды зафиксировал ошибку подряд, после чего был выключен. Его стоит проверить в первую очередь. «Датчик-02» на складе ошибок не показывал, «Термостат-03» ошибся один раз, за ним достаточно просто наблюдать.
